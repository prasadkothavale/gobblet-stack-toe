# gobblet-stack-toe
A repository for gobblet-stack-toe game, UI, analysis, and bots

| Module                    | Description                                            |
|---------------------------|--------------------------------------------------------|
| gobblet-stack-toe-bots    | Module containing bots generated using various methods |
| gobblet-stack-toe-desktop | Desktop version using Electron                         |
| gobblet-stack-toe-engine  | Game engine that plays the game                        |
| gobblet-stack-toe-server  | TBD: Node JS server to host the game                   |
| gobblet-stack-toe-ui      | UI to play the game                                    |


**Live Demo:** https://prasadkothavale.github.io/gobblet-stack-toe/

**Rules:** https://github.com/prasadkothavale/gobblet-stack-toe/blob/main/misc/gobblet_rules.pdf
